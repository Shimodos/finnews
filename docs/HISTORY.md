# История проекта и текущее состояние

Конспект переписки, в которой проект был задуман и написан (облачная сессия Claude Code,
15–16 ноября 2026). Это пересказ, а не дословная запись.

## Зачем проект

Идея пришла из подкаста «Радио-Т»: программа, которая суммаризирует финансовые новости.
Владелец проекта хочет начать покупать ценные бумаги и не знает, с чего начать.

Договорились о рамке: суммаризатор помогает понимать происходящее на рынке и учиться,
но не подсказывает, что покупать. Новости к моменту публикации обычно уже учтены в цене,
поэтому инструмент работает как «объясни и отфильтруй шум», а не как источник сигналов.
Типичная отправная точка для новичка — широкие индексные ETF регулярными небольшими
суммами (это общее наблюдение, не индивидуальная рекомендация).

## Принятые решения

- **Язык: Python.** Обсуждали Go. Go даёт один бинарник и простую параллельность, но он
  многословнее, а его преимущества при 100–200 новостях в день не играют. Python выбран
  за скорость до результата и за финансовую экосистему (pandas для будущего анализа портфеля).
- **Рынок:** США, как самый обеспеченный открытыми данными.
- **Язык дайджеста:** русский при английских источниках.
- **Доставка:** Telegram-бот.
- **Хранение:** SQLite.
- **Модели:** Claude Haiku оценивает важность каждой новости, Claude Sonnet пишет дайджест.
- **Имя репозитория:** `finnews`, приватный. https://github.com/Shimodos/finnews

## Источники данных

Подключены сейчас (RSS):

- Yahoo Finance — общая лента и ленты по каждому тикеру из `WATCHLIST`;
- MarketWatch — главные новости и Market Pulse;
- CNBC — главные новости и финансы;
- Federal Reserve — пресс-релизы.

Запланированы на следующие этапы:

- Finnhub — новости по тикерам, календарь отчётов, котировки;
- Alpha Vantage — котировки и новости с оценкой тональности;
- Marketaux или NewsAPI — агрегаторы новостей;
- SEC EDGAR — отчёты компаний (10-K, 10-Q, 8-K);
- FRED — макроданные (инфляция, ставки, безработица);
- Stooq — исторические цены.

Лимиты бесплатных тарифов надо проверять на сайтах перед подключением.

## Что сделано (этап 1, MVP)

- Сбор лент, очистка HTML, дедупликация по URL и по похожести заголовков.
- Оценка важности 0–10 с привязкой тикеров, пакетами по 25 новостей.
- Дайджест: «Главное за день», «События», «Мой список», «Термин дня».
- Отправка в Telegram с разбивкой длинных сообщений; без токена — вывод в консоль.
- Команды `collect`, `score`, `digest`, `run`, `chat-id`.
- 4 теста, все проходят.

## Что проверено, а что нет

- **Проверено вживую:** сбор новостей. За один проход пришло 113 статей, повторный запуск
  дал 0 новых.
- **Не проверено вживую:** оценка и дайджест через Claude API и отправка в Telegram — в
  облачной сессии не было ключей. Эта часть покрыта только тестами с подменой модели.
- **CNBC** из облака отвечал 403 (блокировка на стороне их сайта). Ленты оставлены в списке:
  с домашнего компьютера могут работать, недоступную ленту сборщик пропускает.
- В вызове дайджеста включён параметр `fallbacks="default"` (бета
  `server-side-fallback-2026-07-01`): при отказе модели API повторяет запрос на запасной.
  Его тоже нужно проверить первым живым запуском.

## Что нужно сделать владельцу

1. Скопировать `.env.example` в `.env`.
2. Получить ключ Claude API в console.anthropic.com и вписать в `ANTHROPIC_API_KEY`.
3. Создать бота через @BotFather (`/newbot`), вписать токен в `TELEGRAM_BOT_TOKEN`.
4. Написать боту любое сообщение, выполнить `uv run finnews chat-id`, вписать число
   в `TELEGRAM_CHAT_ID`.
5. Заменить примерные тикеры в `WATCHLIST` (сейчас VOO, VT, AAPL) на свои.
6. Решить, где будет работать расписание: свой компьютер, VPS или GitHub Actions.

## Следующие шаги

1. Первый живой прогон: `uv run finnews run --dry-run`, затем без `--dry-run`. Исправить то,
   что всплывёт в оценке, дайджесте и отправке.
2. Настроить запуск по расписанию (на Windows — Планировщик заданий; инструкция в README
   написана для cron).
3. Этап 2 — watchlist: Finnhub, цены и календарь отчётов по своим тикерам.
4. Этап 3 — первичные данные: отчёты из EDGAR, макроданные из FRED.
5. Этап 4 — диалог с ботом: вопросы вроде «что эта новость значит для моего ETF».
6. Этап 5, по желанию — веб-дашборд, недельные обзоры, архив с поиском.

## Почему разработка переехала на локальный компьютер

Облачная сессия не смогла запушить код: приложение Claude GitHub App не установлено на
репозиторий, GitHub ответил 403. Код передан архивом, первый push делается с локального
компьютера. Локальная папка проекта: `C:\OpenServer\domains\localhost\finnews`.
