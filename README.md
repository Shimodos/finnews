# finnews

Сайт, который объясняет начинающему инвестору, что происходит на рынках: собирает новости
из США, Европы и Азии, оценивает их важность, переводит на русский и украинский, показывает
котировки и пишет короткий обзор дня. Опубликован на https://finnews.app.

Сайт объясняет новости и не даёт инвестиционных рекомендаций.

## Что на странице

- **Пульс рынка** — индексы США, Европы и Азии и тикеры из своего списка: цена, изменение за
  день, график. Рядом — какие биржи сейчас открыты и когда откроются остальные, с учётом
  праздников.
- **Главное за день** — обзор в 2–3 предложениях, 3–5 ключевых событий и «термин дня».
  Цифры о движении рынка берутся из котировок, а не из заголовков.
- **Сырьё, валюты и бензин** — нефть Brent и WTI, золото, серебро; курсы основных валют и
  гривны; средняя цена бензина на заправках США и ЕС в долларах за литр.
- **Кто двигался и почему** — лидеры роста и падения среди крупных компаний США и одно
  предложение о том, с чем связано движение, со ссылкой на новость. Если новости движение не
  объясняют, так и написано.
- **Экономика в цифрах** — ставки ФРС и ЕЦБ, инфляция и безработица в США и в еврозоне,
  доходность 10-летних облигаций США — с объяснением, что каждая цифра значит.
- **Календарь отчётов** — какие крупные компании отчитываются в ближайшую неделю.
- **Свежие отчёты в SEC** — годовые и квартальные отчёты и сообщения о важных событиях
  крупных компаний США за последние дни, со ссылкой на сам документ. Нужен `SEC_CONTACT`.
- **Лента** — новости с оценкой важности 0–10, сферой, регионом, тоном и фразой «почему это
  важно». Сортировка по времени и важности, фильтры по региону и сфере; заметки об одном
  событии склеены в одну. Заголовок всегда ведёт на оригинал.
- **Обзор недели** — по выходным: изменение индексов за неделю, главные сюжеты, на что
  смотреть дальше и общий вывод.
- **Архив** по дням и неделям с поиском по важным новостям и **словарик** терминов.
- Три языка: английский (по умолчанию), украинский, русский.

## Как это работает

Команда `finnews update` выполняет шаги по порядку:

1. `collect` — читает RSS-ленты, убирает дубли по ссылке и похожести заголовков, складывает
   в SQLite.
2. `prices` — получает котировки, часы работы бирж и календарь отчётов; затем подтягивает
   новости по лидерам дня. `macro` — обновляет макроданные, не чаще раза в 12 часов.
   `fuel` — обновляет недельные цены на бензин, тоже не чаще раза в 12 часов.
   `filings` — получает свежие отчёты компаний из SEC EDGAR (если задан `SEC_CONTACT`).
3. `score` — Claude Haiku ставит каждой новости важность 0–10, тикеры, сферу, регион и тон,
   переводит заголовок и описание и пишет «почему это важно» на трёх языках.
4. `events` — Claude Haiku находит заметки об одном и том же событии.
   `movers` — Claude Haiku по новостям о лидерах дня пишет, с чем связано их движение.
5. `brief` — Claude Sonnet пишет обзор дня на трёх языках, сверяясь с котировками.
   `weekly` — раз в неделю, в выходные, пишет обзор недели (`--force` — написать сейчас).
6. `site` — собирает статические страницы в папку `site/`.

Шаги 3–5 требуют ключа Claude API. Без него страница собирается с оригиналами новостей и
котировками, но без перевода, оценок и обзора. Каждая новость оценивается и переводится один раз.

## Установка

Нужен Python 3.11+ и [uv](https://docs.astral.sh/uv/).

```bash
uv sync
```

```bash
cp .env.example .env
```

Без uv то же самое делается через `python -m venv .venv` и `pip install -e .`; команды тогда
запускаются как `.venv/bin/finnews` (на Windows — `.venv\Scripts\finnews.exe`).

Заполни `.env`:

- `ANTHROPIC_API_KEY` — ключ из https://console.anthropic.com/ (раздел API Keys). Единственное,
  что обязательно для полноценной страницы.
- `WATCHLIST` — тикеры через запятую, за которыми ты следишь: они попадают в «Пульс рынка»,
  по каждому добавляется лента новостей, а новости о них получают оценку выше.
- `FINNEWS_MIN_SCORE` — с какой оценки новость считается важной (по умолчанию 6).
- `FINNEWS_SCORE_MODEL`, `FINNEWS_DIGEST_MODEL` — модели для оценки и для обзора.
- `FINNEWS_SCHEDULE` — время сборок в UTC через запятую (`05:00,12:00`); по нему страница
  показывает, сколько осталось до следующего обновления. Пусто — отсчёта нет.
- `FINNEWS_SITE_URL` — адрес сайта (`https://finnews.app`); нужен только для превью ссылки в
  соцсетях. Пусто — страницы собираются без него.
- `SEC_CONTACT` — твой email для запросов к SEC EDGAR: SEC требует контакт в заголовке
  каждого запроса. Без него блок «Свежие отчёты в SEC» не показывается.
- `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` — только для дайджеста в Telegram (см. ниже).

## Запуск

Всё для сайта одной командой:

```bash
uv run finnews update
```

Страница появится в `site/index.html`. Посмотреть её локально:

```bash
python -m http.server 4397 --directory site
```

Отдельные шаги: `finnews collect`, `prices`, `macro`, `fuel`, `filings`, `score`, `events`, `movers`, `brief`, `weekly`, `site`.
У `brief`, `events`, `movers`, `site` и `update` есть `--hours` — за сколько часов брать новости.

## Публикация

Сайт собирает и выкладывает GitHub Actions — `.github/workflows/publish.yml`:

- запускается четыре раза в день по расписанию и вручную кнопкой «Run workflow»;
- ключ берёт из секрета репозитория `ANTHROPIC_API_KEY`, контакт для SEC — из секрета
  `SEC_CONTACT`, список тикеров — из переменной репозитория `WATCHLIST`;
- базу `finnews.db` хранит в ветке `data` (один перезаписываемый коммит): достаёт её перед
  сборкой и сохраняет сразу после, поэтому оценки не оплачиваются повторно, а архив и
  словарик копятся;
- сборка и выкладка — отдельные задания: упавшую выкладку можно перезапустить, не вызывая
  Claude заново.

Сайт открывается по своему домену `finnews.app`: он указан в настройках репозитория
(Settings → Pages → Custom domain), а DNS-записи домена ведут на GitHub Pages. Файл `CNAME`
в репозитории не нужен.

Расписание записано в двух местах этого файла — в `cron` и в `FINNEWS_SCHEDULE`; менять надо оба.

База на GitHub и локальная `finnews.db` между собой не связаны. Локальные запуски `update`
нужны только для разработки и тратят деньги на API отдельно.

## Источники данных

- **Новости** — RSS: Yahoo Finance, MarketWatch, CNBC (США, Европа, Азия), ФРС, ЕЦБ,
  DW Business, SCMP Business. Список — `FEEDS` в `finnews/config.py`.
- **Котировки и часы бирж** — JSON-адрес графиков Yahoo Finance; календарь торговых дней —
  библиотека `exchange_calendars`.
- **Сырьё и курсы валют** — тот же адрес Yahoo Finance (фьючерсы с ближайшей поставкой и
  валютные пары).
- **Цены на бензин** — еженедельные официальные данные: Управление энергетической информации
  США (страница с таблицей) и «Нефтяной бюллетень» Еврокомиссии (файл xlsx). Для Азии
  открытого источника, который можно читать автоматически, не нашлось.
- **Календарь отчётов** — календарь на сайте Nasdaq.
- **Отчёты компаний** — официальный API SEC EDGAR (без ключа, но с контактом в запросе).
- **Макроданные** — официальные источники без ключа: ФРБ Нью-Йорка (ставка ФРС), Бюро
  статистики труда США (инфляция, безработица), портал данных ЕЦБ (ставка), Eurostat
  (инфляция и безработица еврозоны).

Адреса Yahoo и Nasdaq неофициальные: ключ не нужен, но гарантий нет. Если источник не
ответил, страница собирается без соответствующего блока; у макроданных остаётся прошлое значение.

Праздники и сокращённые дни бирж берутся из библиотеки `exchange_calendars` (календарь на
десять дней вперёд встраивается в страницу при сборке). Обеденные перерывы в Токио и Гонконге
не учитываются.

## Дайджест в Telegram

Первая версия проекта отправляла сводку в Telegram; этот путь остался, но вживую не проверялся.

- `TELEGRAM_BOT_TOKEN` — напиши боту @BotFather команду `/newbot`, он выдаст токен.
- `TELEGRAM_CHAT_ID` — напиши своему боту любое сообщение, выполни `uv run finnews chat-id`
  и скопируй число.

```bash
uv run finnews run --dry-run
```

`run` — это `collect` + `score` + `digest`; с `--dry-run` дайджест выводится в консоль.

## Настройка

- Ленты — `FEEDS` в `finnews/config.py`.
- Индексы, биржи, фонды сфер и список крупных компаний — `finnews/market.py`.
- Инструкции для модели (оценка, склейка, лидеры дня, обзоры, дайджест) — `finnews/llm.py`.
- Тексты интерфейса на трёх языках и оформление — `finnews/site.py`.
- Значок сайта и картинка для превью ссылки — `finnews/assets/`; картинка для постов —
  `docs/promo/finnews-post.png`.
