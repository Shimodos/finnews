# finnews

Статический сайт для начинающего инвестора: новости рынков США, Европы и Азии с оценкой
важности, переводом на три языка, котировками и обзором дня. Опубликован на
https://finnews.app (GitHub Pages со своим доменом). Исходно проект был дайджестом в Telegram — этот путь
остался в коде, но вживую не проверялся.

Предыстория и первоначальный план — в `docs/HISTORY.md` (описывает проект до появления сайта).
Что есть сейчас — в `README.md`.

## Как общаться

- Отвечать по-русски.
- Код в ответах не форматировать, если об этом не просили.

## Команды

- Установка зависимостей: `uv sync` (без uv: `python -m venv .venv`, `pip install -e .`, pytest отдельно)
- Тесты: `uv run pytest`
- Всё для сайта: `uv run finnews update` — collect, prices, macro, fuel, filings, score, events, movers, brief, weekly, site
- Отдельные шаги: `collect`, `prices`, `macro`, `fuel`, `filings`, `score`, `events`, `movers`, `brief`, `weekly`, `site`
- Только пересобрать страницы из базы, без сети и без трат: `uv run finnews site`
- Telegram: `uv run finnews run --dry-run`, `digest`, `chat-id`

## Устройство

- `finnews/config.py` — список лент `FEEDS`, настройки из `.env`.
- `finnews/collect.py` — сбор RSS и дедупликация (по URL и похожести заголовков).
- `finnews/market.py` — котировки и часы бирж (Yahoo Finance): индексы, биржи, фонды сфер,
  список крупных компаний, лидеры дня.
- `finnews/hours.py` — ближайшие торговые сессии бирж с праздниками и короткими днями
  (библиотека `exchange_calendars`, без сети); попадают в снимок котировок под ключом `hours`.
- `finnews/earnings.py` — календарь отчётов (Nasdaq).
- `finnews/fuel.py` — недельные цены на бензин: США (EIA, разбор HTML-таблицы) и ЕС
  (Еврокомиссия, xlsx читается без библиотек); лежат в `store` под ключом `fuel`. Сырьё и курсы
  валют идут в общем снимке котировок (`market.COMMODITIES`, `market.CURRENCIES`).
- `finnews/edgar.py` — свежие отчёты компаний (10-K, 10-Q, 8-K) из SEC EDGAR; лежат в `store`
  под ключом `filings`. Работает, только если задан `SEC_CONTACT`.
- `finnews/macro.py` — макроданные из официальных источников (ФРБ Нью-Йорка, BLS, ЕЦБ, Eurostat);
  хранятся в таблице `store`, обновляются не чаще раза в 12 часов.
- `finnews/llm.py` — вызовы Claude и тексты инструкций: оценка с переводом (Haiku), склейка
  повторов (Haiku), объяснение движения лидеров дня (Haiku), обзор дня, обзор недели и
  дайджест (Sonnet). Обзор недели пишется один раз, в выходные, и лежит в таблице `store` под
  ключом `week:<понедельник>`. Объяснения лидеров лежат под ключом `movers` вместе с отметкой
  `asof` снимка котировок; к другому снимку страница их не прикладывает.
- `finnews/db.py` — SQLite: `articles`, `briefs` (обзор на каждый день), `market` (последний
  снимок котировок и календаря). Новые колонки добавляются через `MIGRATIONS`.
- `finnews/site.py` — сборка страниц: главная, архив с поиском (`search.json`), страницы дней и недель, словарик. Один файл с
  HTML, CSS и JS; тексты интерфейса на трёх языках — словарь `UI`.
- `finnews/assets/` — значок сайта и картинка превью ссылки (`og.png`); `build` копирует их на
  сайт как есть. Превью-теги добавляются, только если задан `FINNEWS_SITE_URL`.
- `finnews/telegram.py` — отправка в Telegram, поиск chat_id.
- `finnews/cli.py` — команды.
- `.github/workflows/publish.yml` — сборка по расписанию и выкладка на GitHub Pages; база
  хранится в ветке `data`.

## Правила

- Ключи и токены лежат только в `.env` и в секретах репозитория; в git и в чат они не попадают.
- Email для SEC EDGAR (`SEC_CONTACT`) — тоже только в `.env` и в секрете репозитория; вписывает
  его пользователь сам. В код, тесты и git он не попадает: репозиторий публичный.
- Инструмент объясняет новости и не даёт советов покупать или продавать конкретные бумаги.
- Модели задаются через `FINNEWS_SCORE_MODEL` и `FINNEWS_DIGEST_MODEL`; идентификаторы моделей в коде не менять без просьбы.
- Команды `update`, `score`, `events`, `movers`, `brief`, `weekly` тратят деньги на Claude API — не запускать их без надобности; для проверки вёрстки хватает `site`.
- Любой текст на странице — на трёх языках (ru, uk, en) через `UI` и `_tr`.
- Yahoo и Nasdaq — неофициальные источники: их отказ не должен ломать сборку, блок просто не показывается.
- Локальная `finnews.db` и база в ветке `data` не связаны; на сайт попадает только вторая.
- Расписание сборок записано в workflow дважды — в `cron` и в `FINNEWS_SCHEDULE`; менять оба.
- Тесты не ходят в сеть: модель, Yahoo и Nasdaq подменяются.
