# finnews

Ежедневный дайджест финансовых новостей в Telegram для начинающего инвестора.
Предыстория проекта, принятые решения и план — в `docs/HISTORY.md`. Прочитай его в начале новой сессии.

## Как общаться

- Отвечать по-русски.
- Код в ответах не форматировать, если об этом не просили.

## Команды

- Установка зависимостей: `uv sync`
- Тесты: `uv run pytest`
- Полный прогон без отправки: `uv run finnews run --dry-run`
- Отдельные шаги: `uv run finnews collect`, `score`, `digest`, `chat-id`

## Устройство

- `finnews/config.py` — список лент `FEEDS`, настройки из `.env`.
- `finnews/collect.py` — сбор RSS и дедупликация (по URL и похожести заголовков).
- `finnews/db.py` — SQLite, таблица `articles`.
- `finnews/llm.py` — оценка важности (Claude Haiku) и дайджест (Claude Sonnet), тексты промптов.
- `finnews/telegram.py` — отправка в Telegram, поиск chat_id.
- `finnews/cli.py` — команды.

## Правила

- Ключи и токены лежат только в `.env`; в git и в чат они не попадают.
- Инструмент объясняет новости и не даёт советов покупать или продавать конкретные бумаги.
- Модели задаются через `FINNEWS_SCORE_MODEL` и `FINNEWS_DIGEST_MODEL`; идентификаторы моделей в коде не менять без просьбы.
